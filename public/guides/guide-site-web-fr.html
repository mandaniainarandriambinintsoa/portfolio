Comptes à créer (par vous)

Créez ces comptes à votre nom ou au nom de votre entreprise. Ajoutez-moi ensuite comme collaborateur avec le rôle indiqué — je n'ai besoin que des accès nécessaires, rien de plus.

GitHub Requis

Hébergement du code source. Votre compte = vous êtes propriétaire du code. Un repo privé suffit pour un site.

Lien : github.com/signup Plan : Free Mon rôle : Collaborator (Write)
Vercel Requis

Hébergement du site. Connecté à votre GitHub : chaque push déploie automatiquement. SSL, CDN mondial et preview par branche inclus gratuitement.

Lien : vercel.com/signup Plan : Hobby (gratuit) suffit pour la plupart des sites Mon rôle : Member
Nom de domaine Requis

Votre adresse web (ex : votreentreprise.com). Achetez-le à votre nom — c'est votre actif le plus précieux. Évitez les domaines offerts par un hébergeur.

Registrars recommandés : porkbun.com, namecheap.com, cloudflare.com Budget : 10–15 €/an
Google Search Console Requis

Vérifie votre propriété auprès de Google et suit l'indexation, les requêtes, les erreurs SEO. Indispensable pour exister sur Google.

Lien : search.google.com/search-console Plan : Gratuit Mon rôle : Utilisateur délégué (Full)
Google Analytics 4 Recommandé

Mesure le trafic : visiteurs, sources, pages populaires, conversions. Gratuit et standard du marché.

Lien : analytics.google.com Plan : Gratuit Mon rôle : Éditeur
Resend (ou équivalent) Recommandé si formulaire de contact

Service d'envoi d'emails transactionnels (formulaires de contact, notifications). Plus fiable qu'un SMTP classique : délivrabilité optimisée.

Lien : resend.com Plan : Free (3 000 emails/mois) Alternative : Brevo, Mailgun, Postmark
Google Business Profile Recommandé si activité locale

Fiche Google Maps / Google Search pour votre entreprise. Essentiel pour le SEO local et la crédibilité (avis clients).

Lien : business.google.com Plan : Gratuit
Cloudflare Optionnel (avancé)

Seulement utile si vous voulez : DNS centralisé avec emails personnalisés, protection DDoS renforcée, ou cache agressif. Vercel inclut déjà CDN + SSL — Cloudflare est rarement nécessaire pour un site simple.

Lien : cloudflare.com Plan : Free

Qui fait quoi

Répartition claire pour qu'on avance vite, sans blocages ni malentendus.

Ce que je fais

  • Design & maquettes (ou intégration d'une maquette fournie)
  • Développement front-end & back-end complet
  • Configuration technique : DNS, domaine, SSL, emails
  • Connexion GitHub ↔ Vercel, CI/CD
  • SEO technique : sitemap, robots, schema, meta, OG tags
  • Installation GA4 / GSC / Resend
  • Tests Lighthouse, responsive, accessibilité
  • Mise en production & vérifications finales

Ce que vous faites

  • Création des comptes listés (p. 02)
  • Achat du nom de domaine à votre nom
  • M'ajouter comme collaborateur aux rôles indiqués
  • Fournir contenu : textes, logo, photos, mentions légales
  • Valider les étapes clés (design, mise en ligne)
  • Répondre aux demandes d'accès Google (validation par email)
  • Paiement des services tiers (domaine, Vercel Pro si besoin)

Contenu à préparer

Plus vous préparez en amont, plus vite on livre. Idéalement avant le démarrage :

Textes — page d'accueil, à propos, services, contact, mentions légales / politique de confidentialité.

Médias — logo (SVG si possible), photos HD, vidéos si besoin, icônes de marque.

Identité — palette de couleurs, polices préférées, exemples de sites qui vous inspirent.

SEO — mots-clés cibles, zones géographiques, concurrents principaux.

Livraison & transfert white label

À la fin du projet, tout est à votre nom. Voici le déroulé de la passation.

Validation finale — parcours complet du site en production, vérification responsive mobile/desktop, tests formulaires et emails.

Transfert de propriété — vous êtes déjà propriétaire de tous les comptes. Je retire mes accès de collaborateur si vous le souhaitez, ou je les conserve pour la maintenance (à votre choix).

Documentation technique — un document PDF listant : URLs, comptes liés, variables d'environnement, procédure de déploiement, contacts d'urgence.

Formation (30 min) — visio pour vous montrer comment modifier les textes vous-même, consulter les stats, gérer les formulaires reçus.

Garantie — 30 jours de corrections incluses après livraison pour tout bug lié au périmètre convenu.

Maintenance (optionnelle) — forfait mensuel si vous voulez que je maintienne le site (mises à jour, petites évolutions, monitoring). Sinon, tout fonctionne en autonomie.
