Monitoring & analytics produit

Pour exploiter votre SaaS sérieusement, vous devez voir ce qui se passe : bugs en prod, parcours utilisateurs, features qui marchent.

SentryRecommandé

À quoi ça sert : quand un utilisateur plante sur un bug en production, Sentry capture le crash avec la stacktrace complète, les données du contexte (navigateur, URL, actions), et m'envoie une alerte. Sans Sentry, vous découvrez les bugs uniquement par les plaintes clients — trop tard.

Lien : sentry.ioPlan : Free (5 000 erreurs/mois) suffit pour démarrer
PostHogRecommandé

À quoi ça sert : analytics produit (pas juste marketing). Funnels (où vos users abandonnent dans l'onboarding), feature flags (activer une fonctionnalité pour 10% des users avant tout le monde), session replay (revoir ce qu'a fait un user avant un bug), A/B tests. GA4 mesure le trafic ; PostHog mesure le comportement.

Lien : posthog.comPlan : Free (1 M events/mois), payant après ça
Google Analytics 4Recommandé

Trafic marketing : sources d'acquisition, pages vues, conversions. Complémentaire à PostHog (qui couvre le produit).

Lien : analytics.google.comPlan : Gratuit
Google Search ConsoleRecommandé

Pour la landing page publique du SaaS. Suivi de l'indexation et du référencement.

Lien : search.google.com/search-consolePlan : Gratuit
cron-job.orgOptionnel (si Supabase Free)

À quoi ça sert : Supabase pause les projets Free après 7 jours sans activité. Ce service ping gratuitement une URL de santé de votre SaaS toutes les 3–5 jours pour garder la base active. Inutile si vous passez en Supabase Pro.

Lien : cron-job.orgPlan : GratuitEndpoint : je crée /api/health que je pointe vers la DB
OpenAI / AnthropicOptionnel (si intégration IA)

Pour les SaaS avec fonctionnalités IA : chatbots, résumés, génération de contenu, recherche sémantique. Vous payez la consommation à l'usage.

OpenAI : platform.openai.comAnthropic : console.anthropic.comPlan : Pay-as-you-go + quota mensuel à fixer

Contenu légal à préparer

Conditions Générales d'Utilisation (CGU) — indispensable. Un avocat peut les rédiger, ou un générateur type Termly/iubenda.

Politique de confidentialité (RGPD) — indispensable dès le premier utilisateur européen.

Conditions de remboursement — claires et affichées avant paiement, conformes à la réglementation locale.

DPA (Data Processing Agreement) — si vous traitez des données personnelles pour le compte de clients B2B.
